# 🚐 ميكروباص القاهرة – Cairo Microbus 3D

لعبة سواقة ميكروباص ثري دي في شوارع وسط البلد، بتشتغل في المتصفح على الموبايل والكمبيوتر من غير تسطيب.

## إزاي تشغّلها

```bash
cd cairo_microbus
python3 -m http.server 8000
# افتح http://localhost:8000
```

أو أي سيرفر static (‏`npx http-server`، GitHub Pages، Netlify…). مكتبة Three.js موجودة جوه المشروع (`js/three.min.js`)، فاللعبة بتشتغل من غير نت (ما عدا خط Cairo من Google Fonts).

## فيها إيه

- **شوارع القاهرة**: شبكة شوارع بأسامي حقيقية (٢٦ يوليو، رمسيس، القصر العيني، طلعت حرب، شبرا، كورنيش النيل…)، جزر في نص الشارع بالبلدورة الأبيض والأسود، نخل وأعمدة نور، عمارات بالبلكونات والغسيل والتكييفات والدش، محلات بيافطات عربي، جامع بمادنتين، جنينة، بنزينة، كمين شرطة، النيل وبرج القاهرة، والأهرامات بعيد.
- **مواقف الميكروباص**: (رمسيس، التحرير، العتبة، الدقي، السيدة زينب، الحسين، شبرا، الجيزة، ماسبيرو) – اقف عند الموقف والركاب يطلعوا، ووصّل كل واحد لمحطته.
- **الأجرة والخناقات**: زرار «الأجرة»، «حد يوصّل الأجرة»، «معاك فكة ميتين؟»، «الأجرة بقت عشرة من أول الشهر!» والركاب بيشتكوا لو سقت بتهوّر أو شغّلت المهرجانات.
- **أصوات الشارع**: بياعين (ترمس، بطاطا، روبابيكيا، عرقسوس بالصاجات، فول، جرايد، غزل البنات…)، سايس، قهوة بلدي، كلاكسات العربيات، خناقات الشارع (أهلي وزمالك، طابور العيش، الركنة، مية البلكونة، التوك توك…)، السواقين التانيين لما تخبطهم، الكمين.
- **الأصوات كلها متولّدة بالكود** (Web Audio): الموتور، الكلاكس، كلاكس المزيكا، الخبطة، الصفارة، وكاسيت بيشغّل مهرجان.
- **الكلام بالصوت**: بيستخدم صوت عربي من الجهاز (Text-to-Speech) ويفضّل اللهجة المصرية `ar-EG` لو موجودة (زي Microsoft Salma / Shakir على Edge وWindows). ولو مفيش صوت عربي، الكلام بيظهر ترجمة وفقاعات فوق الشخصيات.
- **الترافيك**: تاكسيات، توك توك، ميكروباصات، أتوبيسات، ربع نقل – بيمشوا في الحارات ويلفّوا في التقاطعات ويكلكسوا لو وقفت قدامهم.
- **أشخاص** ماشيين على الرصيف وبيعدّوا الشارع من أي حتة (زي القاهرة بالظبط 😅).

## التحكم

| الكيبورد | الموبايل | الوظيفة |
|---|---|---|
| ↑ / W | دواسة البنزين | بنزين |
| ↓ / S | دواسة الفرامل | فرامل (ولو واقف: رجوع) |
| ← → / A D | الدريكسيون | لف |
| Space | – | فرامل |
| H | 📯 | كلاكس |
| J | 🎺 مزيكا | كلاكس مزيكا |
| C | 📣 نادي | تنادي على الركاب |
| F | 💰 الأجرة | تلمّ الأجرة |
| R | 📻 كاسيت | مهرجانات |
| Q / E / X | ⬅ ➡ ⚠ | إشارات وانتظار |
| V | 🎥 | تغيير الكاميرا (ورا / بعيد / من جوه) |
| P / Esc | ⏸ | إيقاف |

## الملفات

```
cairo_microbus/
├── index.html      # الواجهة
├── style.css
└── js/
    ├── three.min.js  # Three.js r128 (MIT)
    ├── utils.js      # أدوات + دمج الأشكال + التصادم
    ├── audio.js      # كل الأصوات المتولّدة
    ├── dialogs.js    # كل الحوارات بالعامية المصرية
    ├── voice.js      # النطق العربي + الترجمة + الفقاعات
    ├── city.js       # بناء المدينة
    ├── models.js     # التكستشرز والعربيات والناس
    ├── traffic.js    # ذكاء العربيات
    ├── people.js     # المشاة والبياعين والمواقف والخناقات
    ├── player.js     # الميكروباص والأحداث
    ├── hud.js        # الشاشة والتحكم
    └── main.js       # اللوب الرئيسي
```

عايز تزوّد حوارات؟ كلها في `js/dialogs.js`.
